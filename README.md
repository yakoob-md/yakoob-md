### 💫 About Me

I am a software engineer dedicated to building high-performance, visually stunning web applications. I focus on bridging the gap between deep mathematical backend calculations and beautiful, responsive UI animations. 

- 🚀 Currently scaling **[Vestora](https://github.com/yakoob-md/Vestora)**, a premium mutual fund portfolio intelligence co-pilot.
- 🎨 Passionate about Glassmorphism, smooth animations (Framer Motion), and reactive architectures.
- ⚡ Believer in clean codebases, 100% type safety, and zero-warning build statuses.
